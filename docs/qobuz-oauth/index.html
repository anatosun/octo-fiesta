Qobuz login for octo-fiesta

This page only hands the one-time code Qobuz just issued to your own octo-fiesta server. It does not store or send the code anywhere else.

No authorization code in the address. Start the login from /qobuz/oauth/login on your octo-fiesta server.

If the address is unreachable from this browser, copy the code and open <server>/qobuz/oauth/callback?code_autorisation=<code> from a device that can reach it (the login must have been started within the last 10 minutes).
